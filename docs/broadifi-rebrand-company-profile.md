## 8. How we work: the process and the human rules

### The process (four steps, always numbered because it is a real sequence)

**01 Understand.** A short, sharp discovery. We map what must exist on day one versus what can wait, and we cost the infrastructure before writing code.
**02 Design.** Humans decide the architecture: boundaries, data model, scaling path, and cost model. Documented before any code is generated.
**03 Build.** AI-accelerated, human-owned. Foundations come from our own tools, generation fills in the well-understood parts, senior engineers write the hard parts and review everything. Tests and CI gate every merge.
**04 Run.** We deploy lean, monitor, and tune cost monthly. Clean handover and documentation are part of the build, not an add-on.

### The human rules for AI (publish these; they are a differentiator)

1. Architecture is decided by humans before any code is generated.
2. Every merged line has a named engineer who owns it.
3. AI output has no shortcut to production. Tests, review, and CI gate everything.
4. No client data, credentials, or secrets ever enter an AI tool. Isolated environments only.
5. We choose maintainability over cleverness, every time.
6. We tell you where AI helped. No hidden generation.
